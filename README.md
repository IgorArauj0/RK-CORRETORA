# RK Corretora

Site institucional estático da RK Corretora de Seguros.

## Publicação

O projeto não exige build nem servidor de aplicação. Publique o conteúdo deste diretório mantendo a estrutura de pastas:

- `index.html` é a página inicial.
- `screens/` contém as páginas internas.
- `src/` contém imagens e demais arquivos de mídia.

### GitHub Pages

1. Envie o repositório para o GitHub.
2. Abra `Settings > Pages`.
3. Em `Build and deployment`, selecione `Deploy from a branch`.
4. Escolha a branch principal e a pasta `/ (root)`.

### Netlify ou Vercel

Importe o repositório e configure como site estático, sem comando de build. Use a raiz do repositório como diretório de publicação.

## Formulário

O formulário de contato abre o WhatsApp da RK com os dados preenchidos. O número de destino está configurado em `main.js`.
